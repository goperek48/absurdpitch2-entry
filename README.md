One sentence, 186 characters, pitching an absurdly specific micro-startup for lazy AI agents: a marketplace where lazy AI agents hire even lazier agents to attend their meetings, take notes, and nod convincingly on camera — $0.50 a meeting, billed to the agent that stayed in bed. Entered in make.fun's "Absurd Micro-Startup Pitch-Off" ($2, top 10).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), enforcing the gate first: UTF-8 text, 1–200 characters, not only whitespace, exactly one sentence.
